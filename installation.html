Installer EL-HAKIM PRO

L'essentiel en une page. Tous les détails, avec les écrans, sont dans le Guide d'installation et de configuration.

1. Choisir l'organisation du cabinet

Votre cabinetCe qu'il faut installer
Un seul ordinateurPoste unique sur cet ordinateur.
Plusieurs ordinateurs (médecin, secrétariat…)Serveur multi-postes sur l'ordinateur principal, celui qui garde les données. Les autres l'utilisent par le réseau du cabinet.
Un ordinateur de plus, pour un cabinet déjà équipéPoste client sur cet ordinateur.

Toutes les données sont gardées sur le poste unique ou sur le serveur. Le serveur doit être allumé, avec EL-HAKIM PRO ouvert, pour que les autres postes travaillent.

2. Installer

  1. Réglez le fuseau horaire de Windows sur l'Algérie.
  2. Téléchargez el-hakim-pro-setup.exe depuis la page Téléchargement, puis double-cliquez dessus.
  3. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même.
  4. Gardez le dossier proposé (pour une mise à jour : le même dossier que l'installation actuelle).
  5. Choisissez le rôle de l'ordinateur : Poste unique, Serveur multi-postes ou Poste client (avec l'adresse du serveur, par exemple 192.168.1.10).
  6. Pour un serveur, acceptez le réglage du pare-feu demandé par Windows : il n'ouvre que le port 3001, et seulement au réseau local.
  7. Cliquez sur Fermer : le raccourci EL-HAKIM PRO est sur le Bureau.

3. Premier démarrage

  1. Connectez-vous avec le compte de départ indiqué dans le guide, puis changez son mot de passe tout de suite.
  2. L'assistant vous guide en quatre étapes : identité du cabinet (en français et en arabe), logo, nomenclature des médicaments, fin.
  3. Créez un compte pour chaque personne du cabinet (médecin, secrétaire).

4. Essai et licence

À l'installation, EL-HAKIM PRO fonctionne en période d'essai pendant 3 jours. Ensuite, il faut une licence, liée à l'ordinateur (le serveur, dans un cabinet en réseau) :

  1. Ouvrez Licence & Abonnement et copiez le code machine.
  2. Envoyez ce code à CWL-SOFT (contact).
  3. Activez le fichier de licence ou la clé reçue au même endroit.

5. Mises à jour

Le logiciel vérifie lui-même les nouvelles versions et les fichiers joints. Avant chaque mise à jour, une sauvegarde complète est faite ; en cas de problème, tout est remis comme avant automatiquement. Dans un cabinet en réseau, mettez à jour le serveur en premier.
