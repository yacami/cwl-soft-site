مستجدات الإصدار 1.4.6

Correction de la licence après mise à jour : mise à jour obligatoire. Vos patients, vos documents, vos comptes

et votre licence sont conservés.

Ce qui change pour vous

  • Votre licence s'affiche correctement. Après une mise à jour, certains cabinets ayant une licence à vie voyaient

« Période d'essai (3 jours) » sur la page Licence et sur le tableau de bord, même après avoir saisi une nouvelle

licence. La page Licence affiche désormais la licence réellement reconnue : « Licence à vie », « Licence 1 an »…

Vous n'avez rien à faire : la licence déjà enregistrée est reprise telle quelle.

  • Si votre licence est refusée, vous savez pourquoi. La page Licence indique la raison et un code à communiquer à

CWL-SOFT (par exemple « licence émise pour un autre poste », code LIC-03), avec le code machine de votre poste.

  • Jamais de blocage sans prévenir. Si une licence qui fonctionnait sur votre poste est refusée (changement de

matériel, licence arrivée à son terme…), EL-HAKIM PRO reste utilisable 7 jours : un bandeau rouge, sur tous les

écrans, indique la raison, les jours restants et invite à contacter CWL-SOFT. Il suffit d'activer la licence reçue

pour que tout redevienne normal.

  • Anciennes licences (activées avant la version 1.4.0) : elles restent acceptées jusqu'au 26/04/2027. La page

Licence affiche un rappel discret : demandez gratuitement votre licence au nouveau format à CWL-SOFT avant cette

date. Rien n'est bloqué d'ici là.

À savoir

  • Le délai de 7 jours n'est accordé qu'une fois par licence et par poste ; il n'est pas renouvelé par une

réinstallation ou une restauration de sauvegarde.

  • Une nouvelle installation sans licence garde ses 3 jours d'essai ; à la fin de l'essai, l'écran « Licence requise »

donne le code machine à envoyer à CWL-SOFT.

إذا ظهرت رسالة Windows «تمت حماية الكمبيوتر الخاص بك»

إنها مصفاة SmartScreen في Windows: تظهر مع البرامج التي لم يتعرّف عليها بعد بشكل كافٍ.

  1. تحقّقوا أولًا من أن الملف آتٍ من هذه الصفحة (البصمة أدناه).
  2. انقروا على معلومات إضافية.
  3. انقروا على تشغيل على أي حال.

التحقق من بصمة الملف

في مجلد التنزيلات، افتحوا PowerShell واكتبوا:

Get-FileHash .\el-hakim-pro-setup.exe -Algorithm SHA256

يجب أن تكون النتيجة مطابقة للبصمة SHA-256 المعروضة أعلاه.

قبل التثبيت

  • حاسوب بنظام Windows 10 أو Windows 11، مع مساحة فارغة تقارب 1 غيغابايت.

  • طابعة تقبل الورق بمقاس A5 وA4.
